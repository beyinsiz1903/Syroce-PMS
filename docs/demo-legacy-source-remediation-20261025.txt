Failure and reversal
--------------------
Pre-commit failure rolls back all source changes and the audit/receipt. A
post-commit cache failure does not return a misleading transaction failure.
There is deliberately no generic overwrite/undo endpoint. Before any reversal,
review the saved before/after hashes, later source use, and appended journals;
use a separately approved compensating operation, not direct snapshot restore.

Local acceptance uses an isolated local replica set only. Required tests include
real transaction rollback, stale/foreign/provider/accepted/financial/room-lock
guards, parallel replay, report conservation, and both GL days with disclosure.
