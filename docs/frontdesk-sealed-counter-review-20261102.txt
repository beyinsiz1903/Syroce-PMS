Problem

Narrow implementation
- Default historical preview and repair retain terminal-reservation rules.
- Finance RBAC remains manage_city_ledger for preview and application.
- Opt in to preview with review_closed_folios=true. Application requires the
  literal JSON boolean true plus this mode's NEW source_revision and reason.
- Only confirmed reservations with ALL closed, stored-zero and ledger-zero
  folios qualify. Checked-in/open/unbalanced/foreign/ambiguous/import-credit
  sources still fail closed. Pending or unknown PSP intents block review.
- Payments must bind to these folios; duplicate provider transactions and
  missing/duplicate folio, payment or charge identities block review.
- Snapshot hashes include folios, charges, extras and provider intents in
  addition to payment and booking counter sources. Stale sources return 409.
- Recompute inside a Mongo transaction; CAS paid_amount and append required
  chained audit in the same transaction. Audit failure rolls back. Parallel
  application has one winner; replay cannot create money or a second audit.
- Only the derived booking paid_amount changes. No payment, charge, stay,
  shift, stock, business date or external payment is created or rewritten.
